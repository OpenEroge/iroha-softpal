## 1. 版本识别与 registered 契约共用（`4581a9d`）

**原生证据**：逐个 handler 比较了 trenka 与 sena 的 registered（Totsulover）实现，比较内容包括参数个数、调试字符串和调用的 PAL 函数。下面这些坐标完全一致：

- SE：5:0–14（其中 5:1 只弹 3 个参数，正好解决了 ADR-0003 里提到的“5:1 参数个数”问题）
- SE 前缀信息：5:8–12
- 历史导航：9:57、10:37–39
- backlog 图标：14:13–19、14:21–24
- 文字动画：2:47
- 其他：3:59、18:54，以及 host 查询 18:88/89/91/96–99

18:90 不一致（trenka 不弹参数），因此排除。

**决策**：新增 `NativeBuild::Trenka`，按完整文件哈希识别，并维护一张逐坐标的共用表 `NativeBuild::shares_registered_extcall`。`registered_softpal` 本身不打开，所以字体、输入、按钮的行为保持不变。`trenka_cn.exe` 不能列为候选文件名：任何一个候选文件对不上哈希，都会让整套安装被判为 Unknown。

**运行时**：5:8、18:88/89/96… 等调用不再报 unimplemented。backlog 里出现了角色头像和语音图标。SE 现在按 lane/前缀音量播放。

## 2. `.ANI` 动作程序（`d41226e`）

**原生证据**：

- 加载：`0x4473E0`，文件最后一个 dword 是入口偏移，label n 位于 `len-0xC-4n`
- 解释器：`0x4466A0`，opcode 0x00–0x16 加上 0xFC–0xFF
- 每帧驱动：`0x446FE0` / `0x447060`
- 清除：`0x447180`
- 各任务回调：`0x402FF0..0x404440`

缓动曲线：mode 1 为 `log10` ×55，mode 2 为 `log10` ×80，mode 4 为 `sin`；op 0x15/0x16 使用 512 项正弦表。`0x13` 是“持久化”标志。程序挂上 sprite 后立即执行，直到第一个等待指令。Koikake 的 `.ani` 用的也是同一种编码。

**实现**：新增 `ani.rs`，是一个完整的解释器；SpriteSystem 为每个 sprite 维护一个播放器；新增 `PalSprite::motion_lanes`，与 action lanes 叠加；3:33 `sp_anime_clear`。

**验证**：本作 351 个程序全部能解析和运行（临时探针，没有提交）。开场线条特效、存档界面 “NEW!” 的缩放、精灵表动画都在动。

**sp_set_pos_ex**：trenka `0x429060` 写的是 wrapper 的位置层（+0x10），审计过的 Game.exe 写的是旋转层，所以按 `NativeBuild` 区分。“NEW!” 现在出现在新存档位的左上角。

## 3. action 段类型 16 / 20（`a3003f3`）

- 17:31（`0x40A230`，类型 16）：source rect 补间
- 17:35（`0x409170`，类型 20）：用 mask 图逐像素显现目标 sprite 的 alpha（`0x401DF0`），结束时把 from 整块复制到 to（`0x402010`）

剧情里的斩击特效原来一直是黑屏，现在能正常显示。四张按类型索引的函数表分别位于 `0x625EE8`、`0x625F40`、`0x625FA0`、`0x626000`。

## 4. 存档标签（`a3ddd58`）

- 缩略图回退：只有本次会话里真正存过的槽位，才允许用内存里的缩略图代替；原来空槽位会显示当前画面
- 字体：原生 `0x42F420` 会应用整组存档字体设置（字号、字体类型、效果、两个颜色），然后恢复；sena 原来强制最小字号 18，导致日期和时间重叠
- 台词：按 `0x431C30` 的规则换行和截断

## 5. TIPS 词典与其他 cat 18 扩展（`94d9502`、`e61317a`、`6734cf4`）

- 18:82–87：读取 4 列 CSV（名称、读音、小图、大图）、五十音行号、两个标志字节、`tips_acc.dat`
- 18:50 / 18:59：存档目录与字符串拼接；文件访问被限制在 `save/` 目录之内
- 18:72 / 73 / 79：全局整数表
- 18:108：场景跳过锁存位

**相关修复**：

- `getprivateprofileint` 现在按 Windows 的规则解析开头的整数。原来 `TIPS_FLAG = 1;` 被读成默认值 0，导致 TIPS 被关闭。
- 四个 INI 函数的文件名改为按 File.dat 解析（原生 `0x44B500`）。

**运行时**：首次启动时读到 `TIPS_FLAG=1`，`tips_csv_read "tips.csv" entries=272`，并写出了 `save/tips_acc.dat`。TIPS 画面能显示五十音分类标签。
